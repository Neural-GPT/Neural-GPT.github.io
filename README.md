# Arjun Gupta — Portfolio

Dark high-contrast portfolio built with Next.js 14 (App Router), Tailwind CSS,
Framer Motion and Recharts. Exports to fully static HTML, so it runs on GitHub
Pages with no server.

---

## Run it locally

```bash
npm install
npm run dev          # http://localhost:3000
```

```bash
npm run build        # static site lands in ./out
npx serve out        # preview the exported build
```

## Deploy to GitHub Pages

### 1. Pick your repo name — this decides one setting

| Repo name | `NEXT_PUBLIC_BASE_PATH` | Site URL |
|---|---|---|
| `Neural-GPT.github.io` | `""` (leave empty) | `https://neural-gpt.github.io` |
| `portfolio` | `"/portfolio"` | `https://neural-gpt.github.io/portfolio` |

Set it in **two** places so local builds and CI agree:

- `.github/workflows/deploy.yml` → the `NEXT_PUBLIC_BASE_PATH` env value
- or `next.config.mjs` → the `BASE_PATH` constant

Getting this wrong is the single most common cause of a deployed site that
loads with no CSS.

### 2. Push

```bash
git init
git add .
git commit -m "Portfolio"
git branch -M main
git remote add origin https://github.com/Neural-GPT/<repo-name>.git
git push -u origin main
```

### 3. Turn Pages on

Repo → **Settings** → **Pages** → **Source: GitHub Actions**.

That's it. Every push to `main` rebuilds and redeploys. The first run takes
about two minutes.

## Before you publish — three files to add

Drop these into `public/`:

| File | What it is |
|---|---|
| `avatar.jpg` | Your portrait for the About section (square, ~600×600) |
| `Arjun_Gupta_Resume.pdf` | The PDF behind the Résumé button in the header |

The favicon (`app/icon.svg`) and the social preview card (`public/og.png`) are
already there.

Filenames are configured in `lib/data.js` under `profile.avatar` and
`profile.resumeFile`, so rename them there if you prefer.

If you skip `avatar.jpg` the About image will 404 — either add the file or
delete the `<Image>` block in `components/About.jsx`.

## Set your real URL in three places

Once you know your Pages URL, update it in:

- `app/layout.jsx` → the `SITE` constant (drives Open Graph, canonical, schema)
- `app/sitemap.js` → the `SITE` constant
- `public/robots.txt` → the `Sitemap:` line

Until you do, link previews on LinkedIn and WhatsApp will point at the wrong
host and the image won't load.

## Regenerating the social preview card

`public/og.png` is the image that shows up when someone shares your link. It's
generated by `scripts/make_og.py` — edit the headline numbers in that file and
re-run it:

```bash
pip install Pillow
python3 scripts/make_og.py
```

Nothing in the site build depends on the script; it just writes the PNG.

## Editing content

**Everything lives in `lib/data.js`.** No component holds copy. Change a
project, a date, a skill value or your email there and the whole site updates,
including the terminal — its commands read from the same objects.

| What you want to change | Where |
|---|---|
| Name, tagline, email, GitHub handle | `profile` |
| Projects | `projects` |
| Internships, nominations | `research` |
| Radar chart values | `skillGroups` |
| Time-split rings | `focusSplit` |
| Tag lists under the charts | `skillList` |
| Timeline entries in the log panel | `logLines` in `components/Research.jsx` |

## The terminal

Live shell in the hero. Supports `help`, `bio`, `projects`, `research`,
`skills`, `education`, `certs`, `contact`, `email`, `open <project>`, `ls`,
`cat resume.txt`, `neofetch`, `theme`, `date`, `echo`, `sudo` and `clear`.
Tab completes, `↑`/`↓` walk history, `Ctrl+L` clears.

Add a command by adding one entry to `registry` in `components/Terminal.jsx`:

```js
uses: {
  blurb: "what I build with",
  run: () => [ok("PyTorch, FastAPI, Next.js")],
}
```

`help` picks it up automatically.

## GitHub contribution graph

GitHub doesn't expose contribution counts on its REST API, so
`components/GitHubActivity.jsx` calls a public read-only mirror of the GraphQL
data from the browser at page load. No token, nothing secret, works on a static
host.

If that service is ever down, a deterministic placeholder grid renders and the
badge switches to `offline` — the section never collapses into an empty box.

To use a different source, replace `fetchContributions`. Anything returning
`[{ date: 'YYYY-MM-DD', count: n }]` will work unchanged.

## Performance and accessibility notes

- The constellation runs one canvas and one rAF loop with a spatial grid for
  neighbour lookups, and stops entirely when the hero scrolls out of view or the
  tab is hidden.
- `GlowCard` writes cursor position to CSS custom properties, so mouse movement
  never triggers a React render.
- Recharts is loaded with `ssr: false` and code-split, keeping it out of the
  initial bundle.
- `prefers-reduced-motion` is respected everywhere: the mesh draws one static
  frame, magnetic hover detaches its listeners, and reveals collapse to a plain
  fade.
- Keyboard focus is visible throughout, heatmap cells are focusable buttons with
  labels, and there's a skip link.
